СЕЙФ АРТЕФАКТОВ НЕКСА — браузерная версия

Как открыть:
1. Распакуйте архив.
2. Откройте index.html двойным щелчком в браузере.

Что изменилось после HTA:
- HTA мог через ActiveX сам читать папку PASSPORTS и двигать файлы в REMOVED_FROM_SAFE.
- Обычный браузер из соображений безопасности не имеет права сам лазить по папкам Windows.
- Поэтому новая версия хранит добавленные паспорта внутри браузера через IndexedDB.

Как пользоваться:
- Нажмите «Положить паспорта в сейф» или перетащите файлы на окно.
- «Открыть» показывает файл в новой вкладке, если браузер умеет его показывать.
- «Скачать» выгружает файл наружу.
- «Вынуть» переносит паспорт в раздел «ВЫНУТО ИЗ СЕЙФА» внутри браузерного сейфа.
- «Выгрузить все паспорта» скачивает все файлы обратно.

Папки PASSPORTS и REMOVED_FROM_SAFE оставлены в архиве как структура проекта и память о старой логике.
